# GENESIS : 우주 만유인력 물리엔진 시뮬레이터

> **"태초의 빈 우주에서 시작하여, 오직 만유인력($F = G \frac{m_1 m_2}{r^2}$)의 영향만으로 상호작용하는 천체들의 운동을 시뮬레이션하고 관찰합니다."**

---

## 🌟 주요 특징

1. **태초의 우주 (The Void & Genesis)**
   - 초기에는 어떠한 외부 중력, 공기 저항, 마찰도 없는 칠흑의 완전한 무(無)의 공간입니다.
   - 마우스 좌클릭으로 첫 번째 천체의 위치를 찍고, **바깥쪽으로 드래그하여 천체의 질량을 원하는 크기로 빚어냅니다.** (초기 속도는 0으로 설정되어 고요히 정지)
   - 두 번째 천체를 원하는 질량으로 창조하는 순간, 두 천체 사이에 상호 만유인력 인력선 및 중력 벡터가 즉시 발동되어 오직 둘 사이의 중력만으로 서로를 끌어당기며 운동을 시작합니다.

2. **실제 물리 단위계 & 실제 시간 스케일링**
   - **실제 물리량**: $G = 6.67430 \times 10^{-11} \, \text{m}^3 \text{kg}^{-1} \text{s}^{-2}$, 질량(kg, $M_\oplus$, $M_\odot$), 거리(m, km, AU)
   - **등간격 시간 배속 스냅 슬라이더 & 원클릭 프리셋**:
     - `1초` : 실시간 1배
     - `1일` : 86,400배
     - `1달` : $2.59 \times 10^6$배
     - `1년` : $3.15 \times 10^7$배
     - `10년` : $3.15 \times 10^8$배
     - `10²년 (100년)` : $3.15 \times 10^9$배
     - `10³년 (1,000년)` : $3.15 \times 10^{10}$배
     - `10⁴년 (10,000년)` : $3.15 \times 10^{11}$배
     - `1광년 (10만년)` : $3.15 \times 10^{12}$배 (초우주적 스케일)
   - **적응형 서브스텝 (Velocity Verlet)**: 1초당 1만년 이상의 극한 배속에서도 궤도가 튕겨 나가지 않고 에너지 보존을 유지하도록 프레임당 미세 시간($dt_{sub}$) 분할 적분

3. **두 점 질량 & 거리 직접 입력 (정밀 생성기)**
   - 좌측 툴바의 `📐` 버튼을 통해 두 물체의 질량과 초기 거리를 수치로 직접 입력하여 원궤도(Circular), 타원궤도(Elliptical), 정면충돌(Stationary) 상태로 생성 가능

4. **실시간 물리 통계 대시보드**
   - 두 물체 간 거리 ($r$)
   - 상호 만유인력 크기 ($F$)
   - 물체별 속력 ($v$)
   - 총 역학적 에너지 보존율 ($E = K + U$)
   - 우주 탄생 경과 시간 카운터

5. **충돌 및 합체 (Accretion / Merge)**
   - 두 천체가 근접하여 충돌($r \le r_1 + r_2$)할 경우, 완전 비탄성 충돌과 운동량 보존 법칙에 따라 하나의 거대 천체로 합체

## 🚀 실행 방법

### 방법 1: 로컬 정적 웹 서버 (권장)
터미널에서 아래 명령 중 하나를 실행한 후 브라우저로 접속합니다:

```bash
# Python 내장 서버
python3 -m http.server 8080

# 또는 npx serve
npx serve .
```
접속 URL: `http://localhost:8080` (또는 터미널에 표시된 포트)

## 🎮 조작법 & 단축키

- **마우스 좌클릭**: 천체 생성
- **마우스 드래그**: 생성할 천체의 초기 속도 벡터 지정
- **마우스 우클릭 / 휠 드래그**: 우주 공간 시점 이동 (Pan)
- **마우스 휠**: 우주 공간 줌 인 / 줌 아웃 (Zoom In/Out)
- **스페이스바**: 시뮬레이션 일시정지 / 재생
- **🎯 버튼**: 모든 천체가 한 화면에 들어오도록 자동 줌 & 포커스
